# 🚀 Career Training System

A comprehensive platform designed to connect **job seekers**, **employers**, and **admins**, with the support of an **AI assistant** 🤖 to enhance career development and training opportunities.

---

## 🛠️ Tech Stack
- **Node.js** ⚡  
- **Express.js** 🌐  
- **React.js** ⚛️  
- **MySQL** 🗄️  

---

## ✨ Features

### 👤 Job Seeker
1. 🔑 **Login / Logout**  
2. 📝 **Register a new account**  
3. 📄 **Upsert Profile (Upload / Update)**  
4. 🔔 **Internal system notifications**  
5. 📧 **Email confirmations and alerts**  
6. 📂 **Upload / Update / Delete / View CV**  
7. 🔍 **Browse jobs and training opportunities**  
8. 🧰 **Search using keywords and filters**  
9. 📝 **Apply for a job or training**  
10. 📊 **Track application status**  
11. 🎯 **Receive job/training recommendations**  
12. 🆕 **Receive notifications for new opportunities**

---

### 🏢 Employer
13. 📢 **Post a job or training opportunity**  
14. ✏️ **Edit / Delete published opportunities**  
15. 👀 **Review applicants for jobs/training**  
16. 🛠️ **Filter applicants by skills**  
17. 🔄 **Update application status**  
18. 📨 **Receive a notification for a new applicant**

---

### 🛡️ Admin
19. 👥 **Manage users (Add / Edit / Delete / Get)**  
20. 🗂️ **Manage jobs and training (Review / Delete)**  
21. 📈 **Generate general system reports**

---

### 🤖 AI Assistant
22. 🛤️ **Suggest career paths**  
23. 📚 **Suggest a learning/training plan**  
24. 📄 **Analyze CV**  
25. 💡 **Provide career advice**

---

## 🎭 Actors
- 👤 **Job Seeker**: Student / Job applicant  
- 🏢 **Employer**: Company / Recruiter  
- 🛡️ **Admin**: System administrator  
- 🤖 **AI Assistant**: Intelligent career helper  

---

## 📌 Project Overview
This system is designed to:  
- Facilitate job and training applications ✅  
- Manage opportunities efficiently 🗂️  
- Provide intelligent career guidance and AI-driven recommendations 🤖  
- Automate notifications for all users 🔔  

The **AI assistant** analyzes CVs, suggests personalized career paths, and provides actionable recommendations to help users optimize their career growth. 🌟
